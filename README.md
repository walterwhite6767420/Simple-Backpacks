# Simple Backpacks

Add five backpack tiers to Minecraft, each with its own storage capacity. Equip a backpack in the dedicated inventory slot and press **B** to open it. You can also use a backpack from your hand.

## Backpack tiers

| Tier | Storage |
| --- | ---: |
| Basic | 9 slots |
| Iron | 18 slots |
| Gold | 27 slots |
| Diamond | 36 slots |
| Netherite | 54 slots |

Backpacks can be upgraded through crafting without losing their stored items. Backpacks cannot be placed inside another backpack.

The backpack slot appears in the player inventory and on the **Inventory** tab in Creative mode.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API
- [MenuKit](https://modrinth.com/mod/menukit)
- [SlotKit](https://modrinth.com/mod/slotkit)
- Java 25 or newer

The mod must be installed on both the client and server in multiplayer.

## Building

Run `gradlew build` (Windows: `gradlew.bat build`). The mod JAR is generated in `build/libs`.
