# Simple-Backpacks
Add five tiers of backpacks to your Minecraft world, from Basic to Netherite. Equip it in the backpack slot and press B. • Basic: 9 slots • Iron: 18 slots • Gold: 27 slots • Diamond: 36 slots • Netherite: 54 slots

Yes, this mod was made with A.I it was for a project I was doing with my friends.
